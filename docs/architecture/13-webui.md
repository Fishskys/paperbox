# WebUI

## 运行边界

自动检查见 [测试行为边界](./testing-policy.md#自动合并检查)。前后端契约检查命令为在 `frontend/` 执行 `npm run check:contracts`，后端须先 `uv sync --locked`。

`frontend/` 是与 API 独立运行的 React + TypeScript + Vite 应用，采用 Ant Design 组件与 Lucide 图标。
开发时 Vite 提供页面及 `/api/*`、`/health` 同源代理，不新增 Python BFF，不调用 Python service 模块。
API 单独启动，前端进程不初始化数据库、后台队列或 MCP；停止前端不影响已提交的后端任务。

## 当前页面

论文库管理对 admin 开放最多 100 篇跨页选择，批量元数据重新提取和重建索引均须先预览并确认，报告逐项列出可执行、无原文、活动任务、变更失败及子任务链接。预览与应用参数必须一致，范围不会扩展到新增匹配论文；修改选择后须重新预览。重建索引的父报告只说明子任务接收/入队，解析索引完成情况由子任务查询。write 保留单篇管理，read 不出现选择和维护操作。个人数据扩展边界见 [设计决定](./adr/0001-personal-data-boundaries.md)。

常规检索的论文信息抽屉及阅读工具栏提供复制引用、BibTeX 与 RIS 下载，使用 read 接口读取最新元数据；操作失败有明确提示。下载引用不要求已有 PDF，也不开放写入权限。

论文库管理的元数据表单按实际字段差异判断未保存内容，提供“撤销编辑”。关闭抽屉、切换论文、站内跳转与浏览器返回均须确认丢弃或继续编辑；刷新及关闭浏览器使用原生离开确认。保存失败及部分拒绝保留未保存输入，后台刷新不会覆盖正在编辑的表单。未变化或全部保存后不提示。

左侧导航、右侧工作区，支持折叠侧栏、小屏抽屉及浅色/深色/跟随系统外观。
导航与路由按后端有效能力开放：read 可访问检索和阅读，write 增加导入和论文管理，admin 增加系统管理。
检索和阅读页面保持只读，包括管理员；常规检索不提供导入或维护入口。
检索包含常规检索、智能检索、检索记录；阅读只保留最近阅读，PDF 阅读器作为详情页进入。
导入包含论文导入与元数据导入；论文管理包含论文库管理和处理任务。任务入口统一为 `/manage/jobs`，覆盖导入、重建索引等处理流程。
`/library` 兼容跳转到 `/search/standard`，保留筛选、分页和锚点；旧标题查询保留 `scope=title` 与入库时间排序。`/imports/jobs` 保留参数跳转到 `/manage/jobs`，沿用 write 权限校验。跳转替换当前历史条目，不增加额外返回步骤。
首次加载与凭证切换时先验证身份，不渲染受保护内容；低权限直接访问受保护 URL 会返回检索页面。
凭证切换会卸载原页面状态和上传队列，停止待传与退避重试，不取消已经被后端接收的任务。
只读身份的连接状态不链接系统管理；连接设置始终可用，显示当前有效角色和标识。
运行状态页调用 `/health`，仅在进入或手动刷新时探测，原样区分正常、异常、禁用和未知状态。
系统管理包含运行状态、数据检查、索引维护和元数据维护。数据检查显式执行三端一致性与 DOI/arXiv 标识核对，可展开论文差异、查看解析器/模型分布和孤立对象，并下载当前返回报告；接口报错或截断会明确标示。
索引维护调用 `/api/papers/reindex`，按检测原因、指定论文 ID 或全库选择，预览后确认入队并提供任务链接。元数据维护及三端对账使用 `/api/maintenance/jobs` 后台任务；元数据先预览，再提交引用该预览的应用任务，处理范围固定，执行前逐篇校验元数据和原文版本。
维护参数改变后旧预览失效；页面不自动执行修复，也不自动重试结果不明的写入。
恢复任务状态期间不再次启动维护；不存在的任务可显式清除视图，不触发替代任务。请求编号在局域网 HTTP 环境也可生成，切换 URL 中的任务编号会切换所查看的报告。
三端检查会完整枚举存储对象，检查数量不受问题列表显示上限限制。任务编号保存在 URL 及按凭证标识隔离的会话存储，页面重开恢复进度与报告；未收到提交响应时按原请求编号查询接收结果，不自动重发写入。任务复用进程内队列及数据库账本，无需新增进程或迁移。排队任务在重启后恢复，执行中任务标记中断并保留已生成报告，需检查后重新预览，禁止直接重试。报告 API 要求 admin。
索引维护的模型普查按 `paper_chunks.embedding_model` 索引统计行数，包含未记录模型的片段；按 ID 和原因筛选在数据库内完成，避免预览单篇时加载全库论文。部署须执行迁移 `f69d4c8a932e`（或 `uv run alembic upgrade head`）。

检索包括论文搜索和本机检索记录，查询、模式及过滤条件保存在 URL。
搜索结果按论文列出证据，只有接口提供真实页码时才定位原文；返回搜索可恢复查询和滚动位置。
阅读器从搜索、论文库或最近阅读进入时，返回操作使用原浏览器历史，保留前进能力，不追加重复来源页。
常规检索未输入关键词时展示完整论文库，包含无原文论文；通过信息抽屉查看仅有元数据的记录。列表由 `/api/papers` 服务端分页，表格上方和下方均提供同步页码与输入跳转，保留当前筛选。
PDF 阅读器使用 React-PDF / PDF.js，按原文尺寸纵向连续排列页面，仅渲染视口附近的页面画布。
滚动同步当前页码、URL 与最近阅读位置，页码输入和前后页按钮滚动定位；支持文本选择、缩放、适应宽度、详情和原文下载。
PDF worker、CMap、字体及 WASM 随本机构建产物提供，不依赖 CDN。
阅读导航抽屉提供 PDF 内置目录、按视口懒加载的缩略图和文内查找。查找读取 PDF 文本层并显示命中页、次数与片段，可跳转并高亮文本项内的字面匹配；跨文本项短语可定位页面，但不保证连续高亮。扫描件无文本层时不会产生虚构命中。
附图页只查询已经生成的附图，保留待复核标记，支持回到原页和下载单幅原始附图；预览与下载携带当前凭证。未提取时显示空状态，不调用可能创建提取任务的 ZIP 下载接口。
检索历史最多 50 条、最近阅读最多 30 条，均仅存在浏览器本地，不代表服务端个人账户记录。

论文管理提供 `/manage/library` 论文库管理，按状态组织维护工作，管理抽屉通过 `paper` 参数定位。状态页签覆盖全部、待补原文、失败、处理中、待处理、已存储、已索引；切换不额外请求各状态计数。
管理页支持按标题、DOI、作者快速定位及上下分页；列表重点展示状态、原文情况和维护操作，年份、刊物与 DOI 作为次要信息显示。点击标题或“管理”打开同一抽屉，也可打开原文核对。完整分面筛选、下载和只读信息浏览集中在常规检索。
两页均通过字段下拉菜单选择作者检索，不提供独立作者输入框；旧链接中的 `author` 条件仍生效，并显示可移除的条件标签。
常规检索的标签控件以 191px 为基准自动填满所在行的剩余空间，期刊会议、年份控件桌面宽度分别为 650px、每项 114px；年份成组换行，小屏控件不超过可用宽度。排序位于上方分页行左侧，窄屏自动换行，与上下分页共享 URL 条件；变更排序重置页码。
列表支持待补原文（空壳论文）、待处理、处理中、已索引、失败和已存储状态，状态可与标题、作者组合筛选；切换筛选重置页码，翻页和刷新保留筛选条件。
状态筛选的精确总数和分页由 PostgreSQL 存活论文状态索引支持，部署须执行 `uv run alembic upgrade head`；不缓存状态计数，写入后重新查询即可获得当前结果。
支持修改元数据、查看来源与字段历史、单篇重建索引、预览后重新提取或清除元数据、确认删除论文。
管理抽屉的“附图”页签支持提取、确认后重新提取、单图及全部删除；删除先请求 `dry_run=true` 预览再确认执行。提取复用后台任务，页签打开时每两秒刷新运行中的任务状态，隐藏页面暂停轮询，失败保留错误并支持手动刷新。无原文时禁用提取。自动提取的 `needs_review` 与质量提示保持可见。
管理页与阅读页均支持单图及整包下载；整包下载固定 `generation_id` 并包含全部资源，未生成版本时禁用，避免调用下载接口隐式启动提取。阅读页不显示图片写操作；写操作仅在论文库管理且具备 write 能力时显示。
元数据表单顶部提供“保存元数据”按钮，滚动编辑字段时保持可见；提交期间禁用表单，成功后显示保存结果，失败保留输入并展示错误。保存仅提交变化的字段，明确保留空值清除语义；修改或清除元数据后提示检索索引需要重建。
无 PDF 的论文显示待补原文，禁用下载、重建与重新提取；阅读器不会请求不存在的原文。
无原文论文可在管理抽屉中选择 PDF，核对目标论文和文件后补传，调用 `POST /api/papers/{paper_id}/file`；接收后显示任务链接，不将接收等同于解析完成。
补传保留目标论文 ID，跳过自动匹配与合并；已有文件、其他进行中任务、相同内容已归属其他论文时拒绝，不覆盖原文。
任务在存储前校验 PDF 内嵌 DOI/arXiv 与目标及其他论文的明确冲突；存储前失败保留无原文状态，存储后失败可沿用原论文重试解析。

论文导入支持多 PDF 选择/拖放、链接提交、两路并发上传及 429 退避；页面保留直达论文管理中处理任务的链接。
论文导入页同时支持 ZIP 上传与服务端目录导入。ZIP 显式提交后显示逐文件结果、拒绝条目和任务链接；目录先预览，再确认正式导入，修改路径、匹配规则、递归选项或处理上限会使旧预览失效。
目录必须位于后端配置的允许根目录内，浏览器选择的本地目录不等于服务端目录；报告可下载，写入请求不自动重试。
元数据导入路由为 `/imports/metadata`，支持 JSON / JSONL / NDJSON 文件，沿用后端 IEEE / CSL / 通用格式识别。
页面通过 `POST /api/metadata/import` 先预览再正式导入，使用 `import_file` 来源，显示匹配、待补原文论文、歧义、失败与冲突报告。
更换文件会清除旧预览，未预览不能正式导入；请求最长等待两分钟，不自动重试写入，网络结果不明时要求先检查论文库或重新预览。
元数据接口同步返回报告，不产生导入队列任务；报告只存在当前页面。
元数据导入页内分为导入与报告、元数据复核。来源详情显示导入值、候选论文的作者、年份、DOI 与文件名、匹配原因和操作历史。支持单条匹配预览、应用唯一匹配、手动选择关联目标、独立入库、拒绝来源及恢复；独立入库和拒绝直接确认，无原因输入。

来源表可跨页选择，批量重新匹配先预览，只提交其中仍待复核且唯一匹配的来源；单条状态过期或归属冲突显示为该条失败，不静默重试或独立入库。已拒绝来源使用独立状态筛选查看和恢复；写操作只在写权限的导入模块内开放。详情确认携带来源版本和预览目标，409 时保持操作上下文并允许刷新。原始记录不被改写，后端审计及迁移要求见[来源归属复核](08-metadata.md#来源归属复核)。字段冲突继续支持保留现值或采纳被拒值。
导入可选择文件、IEEE API、arXiv API、Crossref 或人工整理来源，并限制处理条数；修改来源、条数或文件后必须重新预览，正式导入沿用预览参数。
预览与正式导入报告均可下载为 JSON，包含完整返回明细；页面内报告不跨刷新保存。
复核沿用已有来源挂载、字段 rollback 与 conflict dismiss 接口，不增加独立导航；通过 `tab=review` 可直接打开。
字段冲突仅统计仍需裁决的分歧；按来源优先级已解决及仅格式不同的历史值不计入待复核数量。所有原始来源和字段历史继续在论文库管理的“来源与历史”中保留，不自动修改或批量裁决。
来源和冲突分别使用服务端分页，返回完整总数和稳定顺序；冲突不再限于前段历史记录。裁决成功后重新获取列表，不将加载失败显示为没有冲突。
管理抽屉仅在可见时跟踪补传及重建任务，完成或失败后刷新论文与历史；状态请求失败时显示重试入口，不盲目重发写请求。
PDF 上传自动尝试最多三次，只重试明确拒绝的 429；网络结果不明时提示先检查任务，避免盲目重复提交。
上传队列由工作区持有，应用内切换页面继续传输；刷新或关闭在途页面会触发浏览器离开提醒，不承诺浏览器外后台上传。
“停止待传”只停止等待项与后续重试，已发送请求继续收取结果，已接收的后台任务不取消。
任务列表保留真实阶段和进度；仅在页面可见且存在进行中任务时轮询，失败后保留最后一次报告并允许手动重试。
任务列表与详情使用 `JobOut.kind` 显示真实类型，未知类型保留原值，不根据阶段猜测；支持按论文 ID 与阶段组合筛选，管理抽屉可跳转该论文的任务。
任务详情显示错误码、创建与完成时间、含排队的总耗时；未完成任务按最后更新时间计算已观察耗时，不虚构实时处理时长。
任务详情可展开判重与文件处置事件，查看命中规则、比较证据、目标论文及文件保留/清理结果；历史重复任务没有事件时明确说明未记录依据。
队列状态展示运行、等待、交互与批量队列及并发上限；仅页面可见且存在活动任务或队列积压时轮询，失败明确显示并支持刷新。
系统管理还提供手动只读数据检查，报告含 `errors` 时标记结果不完整，不自动修复数据。

## 凭证与错误

常规检索位于 `/search/standard`，只调用 PostgreSQL 元数据接口，不调用查询改写、向量和重排模型。
字段包括全部元数据、标题、作者、刊物、DOI、arXiv 和摘要；全部元数据不包含正文。每个查询词可跨元数据字段匹配，所有词均须命中。
作者、刊物、年份、文献类型和状态可组合过滤；支持相关度、入库时间、年份和标题排序及稳定分页。筛选项数量来自当前查询结果，按论文计数，每类返回前 50 项。
智能检索保留 `/search`，检索记录分别恢复两种入口及其 URL 条件。
智能检索使用 OpenSearch 原生关键词、向量或混合召回，`recall_k` 为候选论文预算，`top_k` 为每页结果数，WebUI 默认均为 10；显式 URL 参数保留用户设置，每页结果数不得超过召回预算。按 `offset` 在同一候选窗口内翻页，最后一页允许不足一页。
窗口上限 500 篇，界面显示实际召回数、实际后端、改写和重排执行状态；重排未启用或失败时明确显示，不冒充已执行。
智能检索的分页使用 URL 中已提交的每页结果数；编辑表单中的结果数不会改变现有分页，提交新搜索后重置到第一页。
窗口请求以 `total_scope=candidate_window` 表示候选窗口数量，不额外执行语义全库计数；不将窗口大小显示为全库精确命中数。智能检索等待上限 180 秒，切换查询会取消旧请求。
查询改写由用户单独选择，页面默认关闭；常规检索与智能检索的关键词模式均可明确避免查询向量计算，智能检索的重排仍由用户选择。
智能检索的“排除参考文献”开关默认开启；关闭后通过 `filters.include_references=true` 将参考文献切块纳入检索，选择随 URL、翻页和检索记录恢复。

`GET /api/auth/context` 返回有效身份的 prefix、role、source、is_anonymous、auth_enabled、read_access 及 read/write/admin 能力。
接口复用现有鉴权身份，无效凭证始终返回 403；匿名公开读返回 read 能力，要求密钥时缺凭证返回 401，关闭鉴权时保持匿名 admin 行为。
响应禁止缓存且不含密钥或哈希；普通公开读接口的既有权限语义不变。

连接设置中的 API key 只保留在当前页面内存中，刷新后失效；通过 `Authorization: Bearer` 请求头发送。
手动认证模式仅在 sessionStorage 保存无密钥的 explicit 标记；刷新后请求携带 `X-Paperbox-Auth-Mode: explicit`，阻止本机代理自动补充 admin key，按匿名读策略重新验证，写入需要重新提供密钥。
明确清除手动凭证才移除该标记并恢复本机代理身份；标记不是访问控制凭证，后端仍验证实际 API key。
本机开发也可在被 Git 忽略的 `frontend/.env.local` 设置 `PAPERBOX_API_KEY`，由 Vite 开发/预览代理在服务端携带，无需在浏览器中输入。
自动携带仅限本机回环连接、回环 Host 和同源请求；跨源请求或远程客户端不使用本地密钥。浏览器显式提供的凭证优先，错误凭证不会被替换。
该配置只适用于受信任的本机开发，不进入浏览器资源或 Nginx 镜像；独立部署与远程访问仍通过连接设置提供凭证。
密钥不得放入 URL、`VITE_*` 环境变量或浏览器持久化存储。外观选择单独存入本地存储。
请求层集中处理网络故障、401/403 及 `Retry-After`，不会把接口失败渲染为空列表。
无 JSON 响应的 5xx 视为代理或连接故障，显示 API 不可达，不因代理仍在线而显示后端正常。
代理目标配置为 `PAPERBOX_API_TARGET`，默认 `http://127.0.0.1:8077`，此配置不含凭证。

## 开发与检查

在 `frontend/` 执行：

```bash
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npx playwright test --config playwright.production.config.ts
```

Node.js 要求 `20.19+`（20 系列）、`22.13+`（22 系列）或 `24+`，依赖固定于 `package-lock.json`。
开发默认端口 5173；端口已占用时显式传入 `npm run dev -- --port 5175`。
`PAPERBOX_API_TARGET` 可由进程环境或前端 `.env.local` 配置；API 启停方式保持独立。
`vite preview` 只用于本地检查构建产物，不用于正式部署。
浏览器测试使用拦截响应，不写真实论文库；单元测试验证请求与错误契约。
模拟接口测试不能替代已运行 API 的验收。后端代码更新后需要执行数据库迁移并重启 API，Vite 热更新不会更新 Python 进程。
在仓库根执行 `node scripts/check_webui_metadata.mjs`，可用真实浏览器将
`tests/metadata/ieee_metadata_example.jsonl` 和对应 JSON 文件提交给本地 API 做预览，检查记录数、解析失败及论文总数不变，并只读打开元数据复核列表。
该脚本只执行预览，不点击正式导入；默认访问 5173，可通过 `WEBUI_URL` 指定其他地址，需要该页面已具备写权限凭证。
`uv run python scripts/check_webui_permissions.py` 为真实浏览器验收临时创建 read/write/admin 密钥，核对角色导航、只读页面与受保护路由；同时检查管理页状态筛选、DOI 定位和管理抽屉，并采集桌面与移动布局。结束或失败时删除本次创建的密钥，不修改论文。
`uv run python scripts/check_original_attachment.py` 创建临时无原文论文与 write 密钥，验证定向补传、解析索引、原文下载和三端结果；完成后删除本次创建的论文、任务、元数据、对象、索引记录和密钥。
`node scripts/check_webui_jobs.mjs` 只读验证真实任务类型、按论文筛选、队列状态、详情与桌面/移动布局，不触发任务重试。
`uv run python scripts/check_webui_figures.py` 创建临时论文和 read/write 密钥，以真实浏览器验证附图提取、重新提取、只读 ZIP 下载、删除预览与确认、桌面和移动布局；校验 ZIP 清单及原文内容，完成后删除临时论文、任务、图片对象和密钥。
`uv run python scripts/benchmark_paper_list.py --repeat 3 --explain` 只读测量真实论文列表，分开记录计数、分页、关联加载和序列化耗时，并输出 PostgreSQL 实际执行计划。
`node scripts/check_webui_library.mjs` 只读验证管理页实际点击“已索引”的请求耗时、列表结果、刷新保留筛选和桌面/移动布局。

## 独立部署

根 compose 中 `webui` 属于可选 profile，没有 `depends_on`，不会自动启动或停止 API：

```bash
docker compose --profile webui up -d --build --force-recreate webui
docker compose --profile webui stop webui
```

默认访问 `http://localhost:8089`。根 `.env` 的 `WEBUI_PORT` 控制端口，
`WEBUI_API_UPSTREAM` 默认 `http://api:8077`，适合 API 与 WebUI 同在该 compose 网络。
API 运行在宿主机时改成 `http://host.docker.internal:8077`。
前端镜像采用 Node 构建、Nginx 运行，运行阶段不需要 Python、Node 或论文存储依赖。
API 镜像构建上下文排除 `frontend/`，不会携带前端依赖或构建产物。
Nginx 提供 SPA 深层路径回退、静态资源缓存和 API 反向代理，保留客户端 Authorization。
API 域名在请求时解析，因此 API 尚未启动时页面仍可打开，对应业务请求返回网关错误。
默认 DNS 读取容器 `/etc/resolv.conf`；特殊网络可用容器环境变量 `PAPERBOX_DNS_RESOLVER` 覆盖。
反向代理的单请求上传上限为 200 MB，实际接收仍受 paperbox 自身的文件大小与队列限制。
`WEBUI_PROXY_TIMEOUT` 默认 `240s`，应长于前端检索、维护与数据检查请求的三分钟等待时间；该值注入 Nginx 的 `PAPERBOX_PROXY_TIMEOUT`。
部署后可在 `frontend/` 执行 `WEBUI_URL=http://127.0.0.1:8089 npx playwright test --config playwright.deployment.config.ts --workers=2`，在真实 Nginx 静态资源上运行模拟接口回归。
`uv run python scripts/check_webui_deployment.py` 使用临时管理员密钥，比较部署页面与本机 `frontend/dist/index.html` 的入口资源哈希，并验证真实 JSONL 预览、单篇索引与限量元数据维护预览、标识与三端检查、PDF 画布和阅读导航，以及桌面/移动布局；结束或失败时删除密钥，等本次只读后台任务终止后删除这些测试任务，不执行元数据维护写入。运行前先在本机构建前端。

`uv run python scripts/acceptance_pdf_metadata_quality.py --report logs/eval/pdf-quality.json` 使用临时 PostgreSQL schema、OpenSearch 索引及 MinIO 对象，验证来源复核、元数据质量、后台预览/应用、手动字段保护、重复上传审计、引用格式回读及批量子任务报告；始终清理自造资源，不重建真实论文或计算向量。
更新镜像时显式重建 WebUI 容器，避免仅更新同名镜像而继续提供旧资源。已有附图可用时，验收同时核对真实预览和单幅原始 PDF 下载。
`WEBUI_URL=http://127.0.0.1:8089 uv run python scripts/check_webui_permissions.py` 使用临时 read/write/admin 密钥验证部署后的权限分区，结束后清理密钥。

`WEBUI_SOURCE_ONLY=1 uv run python scripts/check_webui_deployment.py` 仅验收元数据导入与来源复核：核对构建哈希、桌面及移动抽屉边界、无原因确认框，以及最多 50 条来源的跨页选择与批量匹配预览。真实来源的写操作被拦截，结束后比较来源快照与审计数量，确认未处理队列；独立入库、拒绝、恢复与失败重试由浏览器模拟接口回归及临时数据库验收覆盖。
`uv run python scripts/check_import_archive.py` 创建临时 PDF，验证 ZIP 条目处置、真实解析索引与原文下载，并清理本次生成的数据；未配置目录白名单时同时核对目录导入保持禁用。

在仓库根执行 `node scripts/check_webui.mjs` 可对已运行服务执行只读浏览器验收，
默认地址 `http://127.0.0.1:5173`，可通过 `WEBUI_URL` 覆盖；用于匿名可读的部署，需要库中已有可读 PDF。
截图写入 `logs/codex/`，覆盖桌面、小屏和真实 PDF 画布；该脚本不创建或修改后端数据。
